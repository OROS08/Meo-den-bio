EROS / MÈO ĐEN — WEBSITE BIO CÁ NHÂN

Trong ZIP có:
- index.html: trang bio
- avatar.jpg: ảnh bạn gửi, được dùng làm ảnh đại diện

Đăng lên GitHub Pages:
1. Giải nén ZIP.
2. Tạo repository mới trên GitHub.
3. Upload cả index.html và avatar.jpg vào thư mục gốc của repository.
4. Mở Settings → Pages.
5. Chọn Deploy from a branch, branch main, folder /(root), rồi Save.
6. Sau khi xuất bản, link thường có dạng https://TEN-GITHUB.github.io/TEN-REPOSITORY/

Trước khi công khai, hãy cân nhắc có muốn để tuổi, chiều cao và cân nặng hiển thị cho tất cả mọi người không.
Các nút Discord/Instagram/Gallery hiện là link mẫu; hãy thay bằng liên kết của bạn.
